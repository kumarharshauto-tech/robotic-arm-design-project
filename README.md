# \# Robotic Arm Design Project

# 

# Engineering design project covering concept development, CAD, QFD, DFMA, FMEA and design selection.

# 

# \## Project Overview

# 

# This project focused on developing and evaluating a robotic arm concept using structured engineering design and quality methodologies.

# 

# The work combined customer requirement analysis, concept generation, design selection, manufacturability assessment and risk analysis.

# 

# \## Objectives

# 

# \- Develop a practical robotic arm design concept

# \- Translate customer requirements into engineering specifications

# \- Compare alternative design concepts

# \- Improve manufacturability and assembly

# \- Identify potential design risks

# \- Produce engineering documentation supporting the final design

# 

# \## Engineering Methods Used

# 

# \- Quality Function Deployment (QFD)

# \- Pugh Matrix

# \- Morphological Analysis

# \- Design for Manufacture and Assembly (DFMA)

# \- Failure Mode and Effects Analysis (FMEA)

# \- CAD Design

# \- Engineering Evaluation
